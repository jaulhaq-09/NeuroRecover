How NeuroRecover AI Works

  
6-phase AI-assisted pipeline — completely read-only.

  
01
🔍 Filesystem Detection
Reads boot sector to identify NTFS, FAT32, exFAT, ext4, HFS+, APFS. Falls back to raw carving for formatted drives. Detects BitLocker, VeraCrypt, LUKS encryption.

  
02
⛏️ Raw File Carving
Scans every byte using 57+ magic-byte signatures across 16 threads. 128MB read buffers. Zero-block skipping. Real thumbnails served immediately as each file is found.

  
03
✦ AI Boundary Detection
Shannon entropy analysis finds natural file endings. Claude AI suggests optimal settings for your device.

  
04
🔧 Auto File Repair
Repairs JPEG SOI/EOI, PNG IHDR/IEND, BMP headers, MP4 moov atoms, AVI idx1. Repaired files replace originals. Tagged in UI as FIXED.

  
05
🗄️ SQLite Deep Recovery
Carves deleted rows from SQLite databases — WhatsApp, SMS, contacts, browser history — even years after deletion.

  
06
📊 Report & Gallery
Generates recovery_report.txt and gallery.html. Claude AI analyzes results, identifies best files, gives personalized next steps.
